# Quick Start: Running Scripts in `rs-py` in Python

## Raw Rankings → Detailed Choice File
### `write_choice_file_detailed.run`

Use this function to convert raw subject data into a detailed `.mat` choice file.

## Import

```python
from src.rs_py.scripts.write_choice_file_detailed import run
```

## Minimal usage

```python
params = {
    "input_path": "/path/to/raw/subject-data/AJ",
    "output_dir": ".",
}

run(params)
```

## Recommended usage with metadata

Add `metadata` when you want the output file to be named with the experiment and subject.

```python
from src.rs_py.scripts.write_choice_file_detailed import run

params = {
    # Required: folder containing the raw subject data
    "input_path": "/path/to/raw/subject-data/AJ",

    # Required: where the output .mat file will be written
    "output_dir": ".",

    # Optional: helps populate output naming and metadata fields
    "metadata": {
        "exp_name": "texture",
        "subject": "AJ",
        "num_sessions": 10,
        "num_trials": 222, # e.g., in this experiment there were 222 unique trials which were repeated
        "stim_list": [
                        "ant", "bat", "bear", "bluebird", "butterfly", "cat", "cow", "crocodile",
                        "dog", "dolphin", "duck", "eagle", "elephant", "fox", "frog", "giraffe",
                        "goat", "goldfish", "hog", "horse", "ladybug", "lizard", "monkey", "mouse",
                        "owl", "pigeon", "rat", "shark", "sheep", "snail", "snake", "sparrow",
                        "spider", "tiger", "turkey", "turtle", "whale",
                    ]
    },
}

run(params)
```

### Parameters

#### Required

* `input_path`
  Path to the raw data directory for one subject.

* `output_dir`
  Directory where the output `.mat` file should be saved.

#### Optional

* `metadata`
  A dictionary of extra information used to label the output and populate the saved metadata.

Common metadata fields include:

* `exp_name`: experiment name, such as `"texture"`
* `subject`: subject ID, such as `"AJ"`
* `num_sessions`: number of sessions, such as `10`
* `num_trials`: number of unique trials
* `num_judgments`: number of comparisons between pairs of stimuli
* `judgment_type`: 'triadic' or 'tetradic' (see Note below)
* `stim_list`: labels for stimuli - autopopulated from raw data if left empty

Other metadata fields may be left blank or omitted if they are not available.

### What the script does

The script reads the raw data, builds the detailed choice structure, and saves a `.mat` file in the output directory.

If `metadata` is omitted or incomplete, the script still runs, but the output filename may be generic.

### Output files

The function writes a `.mat` file to `output_dir`.

Example outputs:

* `./_detailed_choices_.mat`
  Saved when metadata does not provide experiment and subject names.

* `./texture_detailed_choices_AJ.mat`
  Saved when `metadata["exp_name"] = "texture"` and `metadata["subject"] = "AJ"`.

### Note on `judgment_type`:
Use `triadic` for the CSV format obtained if you collect data from the Waraich and Victor (2022) paradigm.

The script expects each trial row to contain a `ref` column and a `clicks` column. `clicks` must be a Python-list string of stimulus column names in click order, and each name must correspond to a column in the same row. The parser reads that list, looks up the clicked stimuli, and generates all pairwise comparisons among the clicked items relative to the reference.

Use `tetradic` only for pair-vs-pair comparisons. In the current code, this affects only how comparisons are standardized and written to the `.mat` file. It is not a separate raw-input format for the Waraich and Victor (2022) click-order CSVs.

### Assumptions made:
This script is only for use with files generated by the Waraich and Victor (2022) paradigm. 
Each row in the CSV files is one trial, trial numbers are assigned sequentially across files, and stimulus labels are mapped to numeric IDs in sorted order before the file is saved.
