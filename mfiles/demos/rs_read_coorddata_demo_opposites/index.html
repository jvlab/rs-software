    rs_read_coorddata_demo_opposites

    Read coordinate data and create a dataset structure in a domain with stimulus coordinates

    data file: 16 stimuli, 3 pairs of opposites also demonstrates interactive choice of files also demonstates quadratic form model

    'which_read' and 'if_builtin' are read from the workspace when they are already defined, and requested at the console otherwise. That is how rs_disp_coordsets_demo_opposites runs this script unattended when it needs the data.

    See also: rs_read_coorddata, rs_get_coordsets, rs_concat_coordsets
